# 2 Recipes To Brew On The Graycano Dripper

## Summary

Two recipes for the Graycano Dripper from The Basic Barista (Australian retailer). Key correction to existing wiki: the Graycano is a **cone dripper** (not flat-bottom) with a large exit hole for fast flow. Flat-bottom brewing is only available via the optional Graycano Coin silicone adaptor. The dripper's differentiating feature is its hollow chamber base, which captures hot air and acts as a heat sink to maintain stable brew temperature.

## Key Claims

- Graycano is a **German** coffee gear manufacturer; sustainability-focused; appeared in Brewers Cup competitions
- Full metal construction; durable scratch-resistant coating
- Core design: large hollow chambers underneath capture hot air → dripper acts as heat sink → maintains stable brew temperature. This is the primary engineering innovation.
- Two cone modes: standard cone filter (fast flow) and wave filter via Graycano Coin (flat-bottom, slower)
- The Graycano Coin is a silicone adaptor that fits inside the Graycano to support Origami Wave Filter Small

## Recipe 1 — Cone Mode

| Variable | Value |
|---|---|
| Dose | 15 g |
| Water | 250 g |
| Ratio | 1:16.7 |
| Temperature | 95°C |
| Grind | ~25 clicks Comandante C40 |
| Structure | 5 equal pours of 50g; wait for near-full drawdown between each |
| Total | 250g across 5 pours |

- Rinse filter before brewing
- First pour (50g) = bloom
- Each subsequent pour: allow previous to nearly drain, then add next 50g
- No explicit timing given — pour-driven, not clock-driven

**Best for:** Washed coffees — "finer grind, extract higher; best for washed coffees to add body and texture"

## Recipe 2 — Wave/Flat-bottom Mode (Graycano Coin)

| Variable | Value |
|---|---|
| Dose | 15 g |
| Water | 250 g |
| Ratio | 1:16.7 |
| Temperature | 98°C |
| Grind | ~30 clicks Comandante C40 (coarser than cone mode) |
| Structure | 50g bloom + 100g + 100g (3 pours total) |
| Total | 250g across 3 pours |

- Insert Graycano Coin first, then Origami Wave Filter Small on top
- First pour (50g) = bloom; wait for drawdown; add 100g; wait; add 100g
- Brew time is slower than cone mode due to Coin restricting flow
- Use a fast-flowing filter to avoid over-long brew time

**Best for:** "More even, cleaner tasting cup… grind much coarser"

## Cone vs. Wave Comparison

| | Cone | Wave (Coin) |
|---|---|---|
| Filter type | Graycano cone filter | Origami Wave Filter Small |
| Temperature | 95°C | 98°C |
| Grind (Comandante) | ~25 clicks | ~30 clicks |
| Pour structure | 5 × 50g | 50+100+100g |
| Flow | Fast (large exit hole) | Slower (Coin restricts flow) |
| Cup character | Higher extraction, body, texture | Even, clean, coarser-ground |
| Best for | Washed coffees | Any; cleaner profile |

## Contradictions / Open Questions

- **Major correction to existing wiki:** `wiki/brewing/concepts/graycano.md` incorrectly described the Graycano as a "flat-bottom dripper with restricted outflow" with "semi-immersion style." This source confirms it is a cone dripper with a large exit hole (fast flow). Flat-bottom requires the Coin adaptor. The concept page has been corrected.
- Temperatures (95°C and 98°C) are significantly higher than the 88–91°C assumed in the bootstrap skeleton — corrected.
- "3 equal pours" language in the wave recipe is loose: the structure is 50+100+100g (not three equal pours). Filed as written above.
- No brew time targets given for either recipe. Grind adjustment is the timing mechanism.
- The Graycano is described as appearing in Brewers Cup competitions — no specific event or year cited.
